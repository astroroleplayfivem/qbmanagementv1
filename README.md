# QB-Management

**Professional, clean, and fully themed QB-Management resource with pre-made business themes.**

## Why this resource is better

This resource is built to improve both the **appearance** and the **functionality** of business management.

It is not just about storing items. It is about making the entire business system feel smoother, cleaner, and more enjoyable to use for both bosses and employees.

---

## Features

* Modern and improved UI
* Pre-made themed layouts for businesses
* Boss stash bonus system
* Deposit functionality
* Withdraw functionality
* Smoother business management flow
* Cleaner stash interaction
* Better overall player usability
* Support for theme integration
* Support for inventory integration
* Support for framework integration
* Organized structure for easier future updates
* More polished and professional presentation

---

## Installation

1. Drag the resource into your server's `resources` folder.
2. Make sure all required dependencies are installed.
3. Add the resource to your `server.cfg`.
4. Import the included SQL file if the resource requires database tables.
5. Configure business settings, stash settings, and permissions as needed.
6. Restart your server.

---

## Dependencies

* `qb-core`
* `oxmysql`
* Inventory system

  * Currently configured for **tgiann-inventory**
* Target system, if required by your setup

---

## Compatibility

This resource is designed to support:

* Theme integration
* Inventory integration
* Framework integration

It has been structured in a way that makes editing, expanding, and maintaining it much easier over time.
